# Heng Li — Academic Homepage

Personal academic homepage for Heng Li, featuring research interests,
biographical information, and publications in extremal combinatorics and
extremal hypergraph theory.

## Website

[https://hengli2026.github.io](https://hengli2026.github.io)

## Local development

```bash
pnpm install
pnpm dev
```

## Deployment

Every push to the `main` branch is built and deployed automatically with
GitHub Actions and GitHub Pages.

## Technology

Next.js, React, and TypeScript.
